# B2B workflow visual sources

Source: [B2B Export Sales Workspace](https://github.com/hql7-luo/b2b-export-sales-intelligence).
The portfolio uses only two visual concepts: the current UI workflow and Analytics.

- `workflow.png`: unchanged copy of `docs/visuals/sales-workflow.png`.
- `workflow-mobile.png`: unchanged copy of `docs/visuals/sales-workflow-mobile.png`, the same six steps in a narrow layout.
- `analytics.png`: unchanged copy of `docs/visuals/sources/analytics.png`.

The original screenshots were captured by real browser actions against the current
application in a fresh disposable SQLite database populated solely with fictional
seed records. Enhanced analysis was disabled; no customer data or API key was used.
The source repository retains the capture script, Pillow layout script and the
commit/date/crop/hash manifest in `docs/visuals/`. The Analytics frame was captured
before adding the walkthrough inquiry and quotation. Its funnel counts are current
stages, not historical cohort conversion; no real sales results are claimed.

The source project uses MIT. Public Streamlit access needs no login, but idle apps
may sleep and require the public wake button and a cold-start wait.
