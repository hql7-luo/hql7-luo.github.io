# Customer investigation visuals

Source: https://github.com/hql7-luo/foreign-customer-investigation-skill

The two bilingual SVG pairs are copied without modification from `docs/visuals/`.
They are generated by `scripts/build_portfolio_visuals.py` from the existing
validated **fictional** Aurora JSON fixture and its English fixture generator.
They show an implemented Agent Skill workflow and a report summary, not web-app
screenshots. Score and grade logic is unchanged. The fictional notice is visible
on both result cards; no customer adoption, revenue or conversion is claimed.

`manifest.json` preserves source and asset hashes, five dimension scores, risk
deduction, total and grade. Rebuild in the source repository, then copy both
languages and the manifest together. Source code and assets use its MIT license.
